# 하루 루틴 (taskmind)

요일별로 고정된 하루 일과를 시간 블록으로 보여주고, 지금 이 순간 해야 할 일을 바로 알려주는 개인용 웹앱.
서버·로그인·빌드 없이 브라우저 안에서만 동작하며, 설치(PWA) 후에는 오프라인에서도 열린다.

## 실행

```bash
npm start          # http://localhost:8000
npm test           # 일정 계산 로직 단위 테스트 (Node 20+)
```

정적 파일만 있으므로 GitHub Pages 등 아무 정적 호스팅에 올려도 된다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 오늘 (기본) | 지금 할 일 카드(남은 시간·진행률·다음 일정) + 하루 타임라인, 완료 체크. 항목을 누르면 상세·메모 |
| 주간 | 요일 × 시간 그리드, 오늘 열 강조와 현재 시각선, ◀ ▶로 다른 주 이동 |
| 월별 | 추가 일정이 있는 날짜에 점 표시, 날짜를 누르면 그날 추가된 일정 목록(편집·추가·하루 일정 보기) |

`+` 버튼으로 특정 날짜에만 적용되는 추가 일정을 넣고, 추가 일정을 누르면 편집·삭제할 수 있다.

## 일정 규칙

- **고정 블록**: 수업, 통학, 식사, 청소, 운동, 자기관리 — 추가 일정과 겹치면 블록마다 처리 방식을 고른다.
  - **남는 시간만**: 겹치지 않는 부분만 남긴다 (일부만 겹칠 때 기본값).
  - **뒤로 밀기**: 추가 일정이 끝난 직후로 옮긴다. 뒤 일정은 자유시간·유동 블록이 먼저 줄어들며 흡수하고,
    모자라면 고정 블록이 줄줄이 밀린다. 24:00을 넘는 부분은 잘린다 (전부 겹칠 때 기본값).
  - **빼기**: 그날만 뺀다 (전부 겹치는 식사의 기본값).
  - 추가 일정끼리 겹치면 저장할 수 없다.
- **유동 블록**: 영어, 독서, 작업 — 겹친 만큼 밀려난다. 그날 남은 **자유시간**이 있으면 그리로 옮기고
  (뒤쪽 가장 가까운 자유시간 우선, 없으면 앞쪽), 자유시간이 모자라면 남는 만큼 단축한다.
- **자유시간**: 빈 칸으로 취급한다. 주간 뷰에는 그리지 않고, 추가 일정이나 밀려난 블록이 채울 수 있다.
- 입력하는 동안 그날 일정이 어떻게 바뀌는지 미리보기로 바로 보여준다.
- **이동 시간**: '이동 시간 포함'을 체크하고 가는 데·오는 데 걸리는 시간(분)을 적으면, 추가 일정 앞뒤에
  통학 블록('이동 (… 가는 길/오는 길)')이 붙는다. 겹침 판단과 처리는 이동 시간까지 포함한 구간으로 한다.
- 완료 체크(기본 블록·추가 일정 모두)는 오늘 날짜에만 동작하고, 날짜가 바뀌면 초기화된다.
- **메모·설명**: 항목을 누르면 상세 창에서 메모를 적을 수 있다(자동 저장). 기본 일정의 메모는 매주 같은 요일·같은
  블록에 반복해서 보이고, 추가 일정의 메모는 그 일정에만 저장된다. 메모가 있으면 타임라인에 첫 줄이 보인다.
- 추가 일정, 완료 체크, 메모는 기기(localStorage)에 저장된다.

## 구조

```
index.html            앱 뼈대(탭바, + 버튼, 시트)
css/style.css         라이트/다크 테마, 반응형 레이아웃
js/data.js            카테고리(색상·고정/유동) + 요일별 기본 일정
js/schedule.js        시간 계산, 추가 일정 반영/재배치(buildDay), 현재 위치(locate)
js/store.js           추가 일정·완료 체크 저장
js/app.js             화면 렌더링과 상호작용
sw.js                 오프라인 캐시
tests/                schedule.js 단위 테스트
```

기본 일정을 바꾸려면 `js/data.js`의 요일별 텍스트만 고치면 된다.
(월요일 '연극과 문화', '여성 커리어 개발'은 각 1시간 30분으로 가정되어 있다.)
